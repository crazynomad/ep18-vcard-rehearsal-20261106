# EP18 Step 2 實操預演

這是綠皮火車 EP18 的獨立部署預演倉庫。人物、履歷、作品與郵箱均為虛構示例。
正式觀眾範本：[vcard-zh-hant-demo](https://github.com/crazynomad/vcard-zh-hant-demo)。
原作：[codewithsadee/vcard-personal-portfolio](https://github.com/codewithsadee/vcard-personal-portfolio)，保留 MIT 授權。

使用 GitHub Pages 的 main 分支根目錄發布，無資料庫、後台密鑰、自訂域名或付費服務。
本次預演會驗證首次發布、手機尺寸、頁籤、篩選、詳情，以及修改後自動更新。
聯絡為 mailto 入口，不是網頁寄信服務；示例郵箱不接收郵件。
